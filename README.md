# تقویم زندگی | Life Calendar

اپلیکیشن فارسی ثبت خاطرات روزانه و مرور تصویری عمر، با تقویم شمسی و رابط کاربری یاسی/بنفش.

## امکانات فعلی
- خانه با آمار عمر و خاطرات اخیر
- نمای کل عمر، سال، ماه و روز
- تقویم شمسی با شروع هفته از شنبه و جایگاه واقعی روزها
- ثبت چند خاطره برای یک روز، عنوان، شرح، ایموجی، دسته‌بندی، رنگ و عکس
- رویداد چندروزه با نوار رنگی پیوسته در نمای ماهانه
- آرشیو قابل جست‌وجو
- دفترچه یادداشت
- تنظیم افق عمر و پروفایل
- یادآوری روزانه با Capacitor Local Notifications در اندروید
- پشتیبان‌گیری و بازیابی JSON
- ذخیره محلی با Dexie/IndexedDB

## پیش‌نیازها
- Node.js 20 یا بالاتر
- npm
- برای ساخت محلی APK: Android Studio/Android SDK و JDK 21

## اجرای وب
```bash
npm ci
npm run dev
```

## ساخت اندروید محلی
```bash
npm ci
npm run build
npx cap add android   # فقط بار اول
npx cap sync android
node scripts/setup-android.mjs   # اصلاحات Safe Area، نوار وضعیت و آیکن (هر بار بعد از sync)
npx cap open android  # بازکردن در Android Studio
```

برای ساخت APK دیباگ:
```bash
cd android
./gradlew assembleDebug
```
مسیر خروجی معمولاً `app/build/outputs/apk/debug/app-debug.apk` است.

## ساخت APK از GitHub
1. کل محتویات پروژه را در یک مخزن GitHub با شاخه `main` قرار دهید.
2. مطمئن شوید `package-lock.json` نیز در مخزن وجود دارد. آن را با `npm install` تولید و commit کنید.
3. به تب Actions بروید.
4. گردش‌کار **Build Android APK** را اجرا کنید (یا به شاخه main پوش کنید).
5. پس از موفقیت، از پایین صفحه اجرای Workflow، Artifact با نام `life-calendar-debug-apk` را دانلود کنید.

GitHub Actions فایل APK دیباگ می‌سازد. برای انتشار عمومی باید نسخه release را با کلید امضای خصوصی خودتان امضا کنید؛ کلید و رمزها را فقط در GitHub Secrets نگه دارید.

## نکات مهم
- تاریخ‌ها با لیست روز/ماه/سال شمسی انتخاب می‌شوند.
- داده‌ها در فضای ذخیره‌سازی محلی همان نصب برنامه نگهداری می‌شوند. پاک‌کردن داده‌های برنامه یا حذف آن ممکن است داده محلی را حذف کند؛ مرتب از بخش تنظیمات خروجی JSON بگیرید.
- عکس‌های انتخابی به صورت Data URL در IndexedDB ذخیره می‌شوند؛ برای تعداد زیاد عکس بهتر است در نسخه بعدی به Capacitor Filesystem منتقل شوند.
- فونت Vazirmatn از بسته `@fontsource/vazirmatn` داخل برنامه بسته‌بندی می‌شود.
- یادآوری واقعی فقط در نسخه اندروید نصب‌شده و پس از دادن مجوز اعلان‌ها قابل استفاده است. مرورگر دسکتاپ صرفاً تنظیم را نگه می‌دارد.
- رویدادهای چندروزه به‌صورت نوار پیوسته روی تقویم ماهانه نمایش داده می‌شوند.
- خروجی پشتیبان در اندروید با پنجره اشتراک‌گذاری ذخیره/ارسال می‌شود.
